# Приватный mock-навык Алисы

Минимальный backend для проверки интеграции Яндекс Диалогов с Yandex Cloud Functions. Навык принимает реплику пользователя и возвращает заранее заданный текст.

## Важно

- YandexGPT не используется.
- Внешние LLM API не используются.
- Сетевых запросов из функции нет.
- API-ключи, IAM-токены модели и роль `ai.languageModels.user` не нужны.
- Ответ можно изменить переменной окружения `MOCK_RESPONSE`.

Это mock-версия: она проверяет доставку запросов от Алисы до Cloud Function и обратно, но не генерирует осмысленные ответы.

## Локальная проверка

```bash
npm ci
npm run typecheck
npm test
npm run package
unzip -t alice-mock-skill.zip
```

Архив `alice-mock-skill.zip` содержит скомпилированный обработчик. В его корне находится `index.js`.

## Настройка ответа

Переменная окружения необязательна:

```text
MOCK_RESPONSE=Всё работает. Это тестовый ответ навыка.
```

Если она не задана, функция отвечает:

```text
Это тестовый ответ навыка. YandexGPT и другие внешние модели не вызываются.
```

## Развёртывание в Yandex Cloud Functions

1. Создайте функцию.
2. Создайте версию функции:
   - среда выполнения: **Node.js 22**;
   - источник: **ZIP-архив**;
   - архив: `alice-mock-skill.zip`;
   - точка входа: `index.handler`;
   - память: **128 МБ**;
   - таймаут: **2 секунды**;
   - сервисный аккаунт: не требуется для mock-ответа;
   - переменная `MOCK_RESPONSE`: по желанию.
3. Дождитесь статуса версии `ACTIVE`.

## Подключение к Яндекс Диалогам

1. Создайте приватный навык Алисы.
2. В поле **Backend** выберите **Функция в Яндекс Облаке**.
3. Выберите созданную функцию.
4. Укажите активационное имя, примеры запросов и иконку.
5. Сохраните и откройте вкладку **Тестирование**.
6. Отправьте любую фразу — навык должен вернуть `MOCK_RESPONSE`.

Для прямого подключения Cloud Function отдельный публичный HTTPS URL не нужен.

## Поведение

- `ping` возвращает `pong`;
- пустой запуск новой сессии возвращает приветствие;
- любая непустая команда возвращает статический mock-ответ;
- ответ соответствует протоколу Алисы 1.0;
- последняя тестовая пара сохраняется в `session_state` в пределах сессии;
- внешние модели не вызываются ни при каких запросах.
